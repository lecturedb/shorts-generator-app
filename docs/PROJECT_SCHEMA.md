# project.json 스키마 v1

`project.json`은 프로젝트의 대표 데이터다. 현재 타입과 런타임 검증 계약은 `lib/project-schema.ts`, 검증을 통과하는 예시는 `fixtures/projects/sample-project.json`에 있다.

## 최상위 도메인

| 필드 | 역할 |
| --- | --- |
| `schemaVersion` | 스키마 호환성 확인. 현재 지원 값은 `1` |
| `project` | 프로젝트 ID, 이름, 시각, 기본 출력 옵션과 전체 상태 |
| `workflow` | 고정 6단계의 포함 여부, 순서, 설정과 상태 |
| `script` | 제목, 훅, 전체 내레이션과 목표 길이 |
| `scenes` | 장면별 순서, 내레이션, 프롬프트, 길이와 자산 참조 |
| `assets` | 이미지·영상·오디오 파일의 프로젝트 내부 상대 경로와 메타데이터 |
| `runs` | 단계 또는 장면 실행의 상태, 시각, 오류 요약과 결과 자산 참조 |
| `output` | 최종 렌더링 설정과 최종 출력 자산 참조 |

## 참조와 상태 규칙

- 프로젝트, 장면, 자산, 실행은 소문자 영숫자와 하이픈으로 된 고유 ID를 사용한다.
- `scene.assetIds`, `asset.sourceAssetIds`, `run.resultAssetIds`, `output.assetId`는 같은 문서에 존재하는 자산 ID만 참조한다.
- 장면에 속한 자산과 실행은 존재하는 `sceneId`만 참조한다.
- 자산 파일은 `/`, `..`, `.`, 빈 경로 조각과 역슬래시가 없는 프로젝트 내부 상대 경로만 사용한다.
- 상태는 `대기`, `실행 중`, `완료`, `실패`, `취소됨`, `확인 필요` 중 하나다.
- 대표 후보는 자산의 `selected`, 선행 결과 변경의 영향은 `stale.isStale`과 `stale.reason`으로 표현한다. 오래된 결과는 참조에서 제거하지 않는다.

## 제외 데이터

- 이미지·영상·오디오 바이너리는 JSON에 넣지 않고 `assets.relativePath`로만 연결한다.
- API 키와 인증 정보는 타입에 포함하지 않는다. 단계 설정에서 키·토큰·비밀값으로 판단되는 이름은 런타임 검증에서 거부한다.
- 실제 파일 생성과 안전 저장은 `lib/server/project-storage.ts`에서 담당하며, 스키마 검증을 통과한 문서만 교체 저장한다.
